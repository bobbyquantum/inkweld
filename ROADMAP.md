# Roadmap

Features that are not in Inkweld yet. For what ships today, see the
[feature list](README.md#feature-list); for what changed in each release, the
[changelog](CHANGELOG.md).

Until 1.0.0 the focus is testing and bug fixing, so nothing below is planned
for the 1.0 betas. Ideas and votes are welcome in
[GitHub Discussions](https://github.com/bobbyquantum/inkweld/discussions).

**Priority:** 🔥 High | 🟡 Medium | 🟢 Nice to have

## Worldbuilding

| Priority | Feature                | Notes                                               |
| -------- | ---------------------- | --------------------------------------------------- |
| 🟢       | Language/conlang tools | Vocabulary lists, alphabets                         |
| 🟢       | Secrets/GM notes       | Per-element spoilers hidden from some collaborators |
| 🟢       | Reference images panel | Images side by side with the document while writing |

## Media library

| Priority | Feature               | Notes                      |
| -------- | --------------------- | -------------------------- |
| 🟢       | Bulk image operations | Multi-select, batch delete |

## Canvas and maps

| Priority | Feature          | Notes                                                                                           |
| -------- | ---------------- | ----------------------------------------------------------------------------------------------- |
| 🟢       | SVG import       | Place an SVG as an image; later, import Inkscape files as editable objects                      |
| 🟢       | AI map restyling | Rough-colour a layer, then restyle it with AI image generation (political, terrain, parchment…) |

## Publishing

| Priority | Feature           | Notes                                                  |
| -------- | ----------------- | ------------------------------------------------------ |
| 🟢       | Presentation mode | Read-only, docs-site-like rendering of a whole project |

## Optional AI features

AI features need admin configuration and are off by default; see the
[AI stance](README.md#data-security--ai-stance).

| Priority | Feature               | Notes                                  |
| -------- | --------------------- | -------------------------------------- |
| 🟢       | AI writing assistance | Suggestions, continuations, rephrasing |

## Operations

| Priority | Feature    | Notes                                 |
| -------- | ---------- | ------------------------------------- |
| 🟢       | Monitoring | Metrics and alerting for self-hosters |
