# Changelog

All notable changes to this project are documented in this file. The project
follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Entries
after 1.0.0-beta.1 are generated by release-please from Conventional Commit PR
titles.

## [1.0.0-beta.1] - YYYY-MM-DD

The first beta of Inkweld 1.0, a collaborative platform for writing fiction
and building the worlds it happens in. Inkweld is feature complete for 1.0;
the betas focus on testing and bug fixing. Please report problems on the
[issue tracker](https://github.com/bobbyquantum/inkweld/issues).

### Writing

- Rich-text editor with tables, images, links, find and replace (Ctrl/Cmd+F),
  project-wide full-text search (Ctrl+Shift+F), word count and reading time,
  zen mode, and optional Markdown typing shortcuts.
- Hierarchical project tree of folders, documents and worldbuilding elements,
  with drag and drop, tags, pinned items, a quick finder and breadcrumbs.
- Scene and note roles for prose, with corkboard and outline views of folders.
- Named and automatic snapshots to restore earlier versions of a document.
- Comments with threaded discussions, and documents that pop out into their
  own window.
- Random name, place and prompt generators.

### Collaboration and sync

- Real-time collaborative editing (Yjs) with live presence, cursors and
  viewer/editor access levels for collaborators.
- Offline-first: projects are kept on the device and sync when a connection
  returns. A browser-only local mode needs no server at all.
- Profiles for several servers or accounts on one device, each with its own
  isolated local data.
- Cloud Sync mode that mirrors projects to the user's Dropbox or Nextcloud,
  with multi-author profiles.
- Fast "Sync All" that only transfers documents that changed.
- Per-device project activation, writing statistics, an activity feed and a
  GitHub-style activity grid on public profiles.

### Worldbuilding

- 29 built-in element types (characters, locations, factions and more) and 54
  relationship types, plus a worldbuilding project template.
- Template (schema) editor that edits a live preview of the element form.
- Per-element schema copies: customise one element's fields in place, and
  pull in later changes to the shared template when you choose.
- Relationship fields and an interactive relationship graph.
- Timelines with custom time systems, eras and events, built automatically
  from element date fields.
- Canvases for maps and boards: layered drawing, pins and regions linked to
  elements, crop frames and live project covers rendered from a canvas.
- Media library with tagging, filtering and image paste, and optional AI image
  generation from several providers (with an admin kill switch).

### Publishing

- Publish plans that export to EPUB 3 (EPUBCheck-clean, with Kindle-friendly
  fallbacks), PDF (Typst), HTML, Markdown and a multi-page website with
  worldbuilding pages.
- Typography settings with bundled fonts, chapter heading styles, typographic
  quotes, an embedded cover and a generated table of contents.
- Project archives (`.inkweld.zip`) for export, import and backup.

### Accounts and security

- Passwordless sign-in with passkeys (WebAuthn) by default. Magic-link
  recovery by email, password sign-in and GitHub OAuth can be turned on.
- User approval workflow, rate limiting on auth endpoints, CSRF protection and
  a Content-Security-Policy.
- Self-service account deletion, in the app and on a public `/delete-account`
  page.

### Integrations

- MCP server so AI assistants can read and edit projects, with OAuth 2.1
  (dynamic client registration) and per-project consent.
- Home Assistant app support: runs behind Home Assistant ingress and signs in
  the Home Assistant user automatically.
- Android app (Trusted Web Activity) and an Electron desktop build.

### Administration

- Admin settings for users, AI providers, email and site configuration.
- Branding: custom login and home backgrounds, privacy policy and terms pages
  with optional acceptance, and custom HTML injection for analytics or consent
  tools.
- Per-user sync capacity (storage quotas), measured always and enforced when
  enabled.
- Interface available for translation (Transloco), with English as the source
  language.

### Self-hosting

- Single Docker image (`ghcr.io/bobbyquantum/inkweld`) or a native Bun server
  with SQLite and per-project LevelDB storage.
- Cloudflare Workers deployment with D1, R2 and Durable Objects.
- Interactive deployment wizard (`bun run deploy`).
