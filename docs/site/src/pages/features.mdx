## Private by design

- **Self-hosted** — your manuscripts live on hardware you control. No telemetry, no third-party cloud.
- **Passwordless sign-in** — passkeys (Face ID, Touch ID, Windows Hello, security keys) by default, with optional password login and GitHub OAuth.
- **Role-based sharing** — invite collaborators per project with the access they need, and see what changed in the activity feed.
- **AI is opt-in** — every AI feature is disabled until an administrator turns it on, and a single kill switch turns it all off again.
- **No lock-in** — export to open formats, or take a complete project archive with you.
- **Open source** — MIT licensed, built in the open on [GitHub](https://github.com/bobbyquantum/inkweld).

## Under the hood

| Layer          | Technology                                         |
| -------------- | -------------------------------------------------- |
| Client         | Angular PWA, ProseMirror editor, IndexedDB storage |
| Real-time sync | Yjs CRDTs over WebSocket                           |
| Server         | Hono on Bun, or Cloudflare Workers                 |
| Database       | SQLite via Drizzle ORM, or Cloudflare D1           |
| Publishing     | EPUB, Typst-rendered PDF, HTML, Markdown           |
| Integrations   | Model Context Protocol server with OAuth           |

Want the details? Read the [architecture guide](/docs/developer/architecture) or browse the [REST API reference](/docs/developer/api).
