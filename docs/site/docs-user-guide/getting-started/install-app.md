# Installing the App

Inkweld is a web app you can install. Once installed it opens from your home
screen, dock or start menu in its own window, works offline, and updates
itself. Your projects stay exactly where they were: installing doesn't move or
copy any data.

When your browser can install Inkweld, the bookshelf shows an **Install
Inkweld** card. If you dismissed it, use **Settings → General → Install app**
instead.

## Chrome, Edge and other Chromium browsers

This covers Android phones and tablets, Windows, macOS, Linux and ChromeOS.

- Click **Install** on the card (or in Settings), then confirm.
- Or use the browser itself: the install icon at the right of the address
  bar, or the menu (⋮) → **Install Inkweld** (on Android: **Add to Home
  screen** → **Install**).

## iPhone and iPad

1. Open Inkweld in Safari (other iOS browsers work too, from iOS 16.4).
2. Tap **Share**, then **Add to Home Screen**.
3. Tap **Add**.

## Firefox and other browsers

Desktop Firefox doesn't install web apps; use Inkweld in a tab, or install it
from a Chromium browser. Firefox on Android offers **Install** in its menu.

## Self-hosted servers

Installing works the same from your own server's address. Each address is a
separate app with its own local data, so install the one you use.
