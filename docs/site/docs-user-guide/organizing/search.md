# Navigation

Navigate your project using the project tree in the left sidebar.

## Project Tree

The project tree shows all your documents, folders, and worldbuilding elements in a hierarchical structure.

### Basic Navigation

- **Click** a document or other item to open it in a tab
- **Click** a folder to expand or collapse it
- **Double-click** a folder to open its folder view (corkboard, outline, grid or list). With [Clicking a Folder Opens It](../settings/user-settings#clicking-a-folder-opens-it) turned on, a single click does both
- **Right-click** for context menu options
- **Drag and drop** to reorganize elements
- Press **Enter** on a focused item to open it (or to expand or collapse a folder)

### Toolbar Buttons

At the top of the project tree:

- **Home** — Return to the project home tab
- **Search in Project** — Open [Project Search](./project-search) to find or browse elements

New elements are created with the **Create** button at the bottom of the project tree. See [Managing Documents](./documents#creating-documents).

## Element References

Use `@mentions` to navigate between connected elements:

1. Type `@` in any document
2. Search for characters, locations, or items
3. Select to insert a clickable reference
4. Click any reference to jump to that element

See [Element References](../worldbuilding/element-references) for details.

## Tabs

Open documents appear as tabs at the top of the editor. Click tabs to switch between open documents, or drag them to reorder. Right-click a tab for options like Close, Close Others, Rename or Open in New Window.

## Project-wide Search

Press `Ctrl/Cmd + Shift + F` (or click the search icon in the sidebar toolbar) to search across **all documents** in your project at once. Results show matching snippets with the search term highlighted, and clicking a result opens that document directly.

See [Project Search](./project-search) for full details.

## Find in Document

Press `Ctrl/Cmd + F` while editing a document to open the find bar. This lets you search for text within the current document, navigate between matches, and optionally replace text. See [The Editor — Find and Replace](../writing/editor#find-and-replace) for full details.

## Media Search

The [Media Library](../media/library) has a search bar (**Search media, elements, or tags...**). It matches a file's name, its ID, or its AI generation prompt, as well as the names of the elements and tags the file is linked to.
